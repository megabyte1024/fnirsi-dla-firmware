# FPGA design for FNIRSI DLA-16 Plus

Design for the analyzer's FPGA, a Pango PGL22G in package MBG324. Not written yet.

- It is built with Pango Design Suite (PDS) and its licence, by a script of its own; the CMake build of the MCU
  firmware does not need PDS.
- Files that PDS generates (IP cores, simulation models, reports, bitstreams, project folders) are not kept in this
  repository; the build makes them again.
- Licence: MIT, like the rest of the repository.
